## 开发约定

- Node.js 24+，原生 ESM，无编译步骤。按任务选择强度、明确文件归属、成员短交接，队长负责集成验收；小任务直接完成。
- `npm run test:native`：默认包快速回归，无项目依赖安装要求。
- `npm test`：完整功能回归；`npm run test:coverage`：src覆盖率与完整回归。strict测试需要已有项目依赖，不调用真实模型。
- `npm run build -- --out <新目录>`：生成默认包；加 `--strict` 显式准备严格包。构建不安装到用户配置。
- 运行验证前告知用户固定提示；检查实际执行数量与退出码，不用成员完成或历史绿测替代当前验收。
