## 开发约定

- Node.js 24+，原生 ESM，无编译步骤和新增依赖需求。
- `npm run test:native`：默认包快速回归，无项目依赖安装要求。
- `npm test`：全部回归，涉及严格实现时需要已有项目依赖；不调用真实模型。
- `npm run build -- --out <新目录>`：生成默认包，不安装到用户配置。
- 队长维护共享 STATUS 与 TODO；成员只写分配的文件，不同时改共享配置。
- 保留用户既有改动、HEAD 和暂存区；commit、push、正式 update、历史状态清理按用户指令分别处理。
